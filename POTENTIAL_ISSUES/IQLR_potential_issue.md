Incorrect feature subsetting logic in IQLR and ZERO denominator modes
In the IQLR and ZERO denominator modes, line 141 attempts to index `feature_subset[i]` where `i` is a condition index. However, `aldex_set_mode` returns a single flat vector of feature indices (not condition-indexed). The code incorrectly treats this vector as if it were indexed by condition, causing index misalignment. Additionally, indexing with `feature_subset[i]` yields only a single feature index, but the logic requires all features in the subset for calculating the geometric mean. This results in incorrect CLR calculations for IQLR and ZERO modes.
